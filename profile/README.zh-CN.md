## ✨ 我们的五项工作原则

- **我们开发自己需要的工具。** 迄今为止，每个产品都始于我们当中有人用现有工具完成不了的任务。发布后我们仍在自己的电脑上使用它，所以粗糙之处总是先被我们发现。
- **我们秉持健康的完美主义。** 我们在意细节，会反复打磨每个版本，直到用起来恰到好处。我们也知道何时停下，因为一直等待完美的工具帮不了任何人。
- **我们认真对待每一条来信。** 每一封来信都会有人完整读完，无论是报告问题还是提出想法。反馈是我们收到的最有价值的意见，也决定了我们接下来做什么。
- **我们坚持务实的美学。** 我们希望产品美观，但每一个视觉决定都必须让工具更易读或更好用，才会被保留下来。
- **我们以成熟的成果为基础。** 当经过充分验证的引擎已经解决了难题，我们就在其基础上构建，把精力放在你直接接触的部分。没有合适的方案时，我们会自己编写这一部分。

## 🔒 四项承诺

这些承诺适用于我们现在和今后发布的每一款产品。

- **你的数据属于你。** 你可以用易读的格式导出数据。我们不会用这些数据建立你的用户画像。
- **我们的产品没有广告。** 我们不投放广告，也不会收钱把他人的利益置于你的利益之上。
- **我们会说明产品如何工作。** 文档会用清楚的语言说明所有可能影响你信任的功能。
- **没有我们，产品也能继续运行。** 如果我们停止维护，已安装的产品仍会继续运行。我们会提前通知支持结束的时间。
